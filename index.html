日志

v3.2.0 · 2026-10-28

  • 新增「运动」界面风格：无衬线大字、白卡片、荧光绿重点。新手设置第一步和「我 → 外观」里都能切换，原来的「纸墨」原样保留。新装默认运动，已经在用的保持纸墨。
  • 运动风格的今天页：「下一项」大卡片写着组 × 次和重量，做完一组点一下，自动开始组间倒计时，可以加 15 秒或跳过；顶上的圆环显示主项做完几个。
  • 「做到第几组」只记在这台手机上；换手机只丢组数，「做完没有」照常同步。

v3.1.0 · 2026-10-28

  • AI 教练进到各页（已开通才有）：今天顶上每天一段「教练的话」；换动作选了原因，教练按原因挑替代；打卡后教练马上看这次的记录，身体不适可以一键加进「身体情况」。
  • 每周第一次打开「记录」自动生成本周复盘。
  • 和教练聊天时，教练可以提议改计划、重量、器械和训练设置，点「采纳」才生效，采纳后能撤销。

v3.0.0 · 2026-10-28

  • 五页导航：今天 / 计划 / 记录 / 教练 / 我，导航固定在底部。
  • 旧「设置」全部搬进「计划」和「我」，一项没删；滑块换成 −/+ 步进器。
  • 新手设置五步，和「计划」是同一套开关；「我」里可以重走。
  • 勾选框统一成自绘方框，点击区 44px，键盘空格可切换。
  • 换动作面板：只今天划掉 / 永久排除分开；动作详情的替换和划掉移到顶部。
  • 复盘搬到「记录」顶部，AI 排计划搬到「计划 → 08」，模型和思考深度搬到「我」。
  • 弹窗统一用 Esc 关闭；可以双指缩放；最小字号 11px。

v2.1.0 · 2026-08-04

  • 训练量与下调控制：提前结束训练可自主勾选是否下调剩余训练量，设置中可开关默认下调。
  • 全局休息与后台恢复：逐动作快捷开启组间休息计时；sessionStorage 状态恢复，切回前台自动接续。
  • 动作划掉与排除：动作和详情里都能划掉 / 永久排除，设置中随时恢复，AI 分析导出带上排除清单。
  • 灵活动作库与加练：「+ 手动添加动作」优先按当日肌群筛选；能换的动作都可一键替换。
  • 开源解剖图：接入 wger 人体解剖 SVG，标出主发力和辅助肌群。
  • 水疗恢复模块：游泳日按总时长配比游泳与桑拿 / Hot Tub / 热躺椅时间，支持 7 段冷热交替引导。
  • 系统通知与提示音分开开关。
  • 离线预载图标字体与解剖图。
